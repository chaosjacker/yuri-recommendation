# 🌸 百合推薦表

**台灣繁體／簡體雙語版**

> 一份安靜整理的百合作品清單，收錄漫畫、動漫、廣播劇、小說與遊戲。

<br>

## ✨ 功能

| 功能 | 說明 |
|------|------|
| 🌐 雙語切換 | 一鍵切換繁體中文 ↔ 簡體中文 |
| 🗂️ 分類標籤 | 漫畫／動漫／廣播劇／小說／遊戲 快速切換 |
| 📱 手機友善 | 針對小螢幕優化排版與觸控 |
| 📖 完整展示 | 每部作品附狀態、類型與備註 |

<br>

## 🚀 使用方式

1. 下載或直接開啟 `index.html`
2. 上方可切換「繁體中文」或「简体中文」
3. 點選分類標籤即可只看想看的類型

> 建議使用現代瀏覽器（Chrome、Safari、Edge、Firefox）以獲得最佳體驗。

<br>

## 📂 檔案說明

```
yuri-recommendation/
├── index.html          ← 主頁面（雙語 + 分類標籤）
└── README.md           ← 本說明文件
```
